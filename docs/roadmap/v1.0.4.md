# v1.0.4 — Stabilization

**Type:** patch · **Status:** shipped in [#101](https://github.com/ycechungAI/cmd-ssg/pull/101) · **Depends on:** nothing

## Goal

The CLI never crashes with a stack trace, never writes files to the wrong path, and ships no dead dependencies. Behavior changes are limited to bug fixes.

## Scope

Bugs B1–B6, B8–B12, B17–B19 (see [README](README.md#bug-index)), plus repo and dependency hygiene. B7 (auto-deleting `./dist`) is **not** in scope here. It needs a new flag and is covered in v1.1.0.

## Changes

### CLI entry (`bin/index.js`)

- **B1/B19:** read the version from `require("../package.json").version` and register it with `program.version(version, "-v, --version")`. Delete the custom `-v`/`-h` options and the hand-written `helpMsg`, and let commander generate help from the option descriptions so `-c` shows up automatically. Fix "cmd-svg" to "cmd-ssg". The figlet banner goes in `program.addHelpText("beforeAll", …)` so it only appears with help.
- **B18:** remove `clear()` and the `clear` dependency.
- **B2/B3/B4:** restructure into one entry point:
  ```js
  async function main(argv) { … }
  main(process.argv).catch((err) => {
    console.error(chalk.red.bold(err.message));
    process.exitCode = err.exitCode ?? 1;
  });
  ```
  - Resolve options as `{ ...defaults, ...configFile, ...cliFlags }`. The CLI wins (B17).
  - With no input from either source, print `error: no input given (use -i <path> or -c <config>)` plus the usage line, and exit with code **2**.
  - Use `const` for all locals. `await convertToHtml(...)`.
- **B17:** config loading:
  - A missing file gives `Config file not found: <path>` (exit 2).
  - Invalid JSON gives `Config file is not valid JSON: <path> (<parser message>)` (exit 2).
  - Only `input`, `output` and `stylesheet` are read. Unknown keys are ignored in 1.x (they become an error in v2.0.0).
  - Keep loading via `fs.readFileSync` + `JSON.parse`. Never `require()` it (see sentinel 2026-02-01).

### Errors (`bin/helper.js`)

- Replace `displayError` (log + set exitCode + throw) with a small `CliError extends Error { exitCode }`. Library functions throw `CliError` and only `main` prints. Keep the existing exit codes (3 = cannot create folder, 7 = processing, 8 = index write).

### Output folder (`bin/outputCheck.js`, `bin/helper.js:149-166`)

- **B5/B6:** `const out = path.resolve(options.output ?? "dist")`. All comparisons use resolved paths.
  - Path doesn't exist: `fs.mkdir(out, { recursive: true })`.
  - Path exists and isn't a directory: `CliError("Output path is not a directory: <out>", 2)`.
  - **Keep** the existing "wipe default ./dist" behavior in this patch, but only when `out === path.resolve("dist")`. That way `"dist"` and `"./dist"` behave the same, and nothing else gets deleted.
  - Refuse when `out` equals or contains the input (prevents writing into the source or deleting it). An output folder _inside_ the input folder is allowed and skipped during discovery, so `ssg -i .` keeps working.

### Discovery and paths (`bin/helper.js`)

- Add one module-level `const PAGE_EXTENSIONS = [".txt", ".md"]`. Use it in `isFileCheck`, `getAllFiles`, both checks in `checkInput`, and error messages. Remove the inline `extname === …` chains.
- **B11:** `.css` is no longer a page source. `checkInput("x.css")` errors with "File must be a .txt or .md file". In a folder, `.css` files are skipped (copying them as assets comes in v1.1.0).
- **B8:** the relative path of each file is `path.relative(inputRoot, absFile)`. The output file goes to `path.join(out, relDir, outName)`. Delete both `split(/\\|\//).shift()` blocks. For single-file input, `inputRoot = path.dirname(input)`.
- **B9:** `outName = path.parse(file).name.replaceAll(" ", "_") + ".html"`. Before writing anything, build a `Map<outRelPath, srcRelPath>`. If two sources map to the same output, warn `Skipping b/a.md: output b/a.html already produced by b/a.txt` and keep the first one in sorted order, so the result is deterministic.
- **B10:** if a source maps to `index.html` at the output root, **do not** generate the menu page. Print `Using <src> as index page` instead.
- Route URLs are computed from `relOut` with `/` separators: `relOut.split(path.sep).join("/")`. Remove `substr`.
- Replace `util.promisify(fs.readFile)` with `fs.promises.readFile`.
- `createHtmlFile` and `createHtmlFileTest` share a new pure `renderPage(basename, data, stylesheet)`. `createHtmlFileTest` becomes a thin alias kept for test compatibility.

### Template (`generateHtmlTemplate.js`)

- **B12:** emit `<link rel="stylesheet" href="…">` only when `options.style` is a non-empty string, in both templates.

### Repo and dependency hygiene

- `package.json`:
  - Remove `fastify`, `yargs`, `yargs-parser`, `y18n`, `@types/yargs`, `cli-boxes`, `clear`, `@typescript-eslint/*`. Keep `boxen` only if it's still used after the help rewrite, otherwise remove it.
  - `engines.node` → `">=18"`. Remove `engines.npm`.
  - Delete the `pkg` block.
  - `version` → `1.0.4`.
- Git:
  - `git rm --cached -r dist test/index.html .vs`.
  - Add `.DS_Store` to `.gitignore`.
- `config.json`: `input` → `"sample_txt"`, `stylesheet` → `"sample_css/new.css"`, drop the `future-implementation` key.
- `.eslintrc.json`: `env: { node: true, es2022: true, jest: true }`, `sourceType: "script"`. Remove every `/* eslint-disable no-undef */` and `no-unused-vars` header, and fix what surfaces. Stay on ESLint 7 here; the upgrade is in v1.1.0.
- `.jules/sentinel.md`: collapse the ~12 duplicate "control characters in URL scheme" entries into one consolidated entry. Keep the distinct ones: template XSS, stylesheet XSS, config `require()`, scheme blocklist, multi-encoding, HTML entities and symlinks.
- README: update the version, list the actual flags, and add an exit-code table.
- CI (`.github/workflows/node.js.yml`): drop the `browserslist --update-db` step and use the matrix `node-version: [18, 20, 22]`.

## Behavior & acceptance criteria

| Scenario                          | Expected                                                       |
| --------------------------------- | -------------------------------------------------------------- |
| `ssg` (no args)                   | Usage plus "no input given" on stderr, exit 2, no stack trace  |
| `ssg -v` / `--version`            | Prints `1.0.4`                                                 |
| `ssg -h`                          | Banner plus commander help listing `-i -o -s -c -v -h`         |
| `ssg -i missing.txt`              | `Directory or file must exist.` exit 2                         |
| `ssg -i a/b/docs -o out`          | `out/<relative tree under docs>`, no `b/` prefix               |
| `ssg -i /abs/docs -o out`         | Same layout as relative input                                  |
| `ssg -i docs -o newdir` (missing) | `newdir` created and the site written                          |
| `ssg -i docs -o README.md`        | `Output path is not a directory`, exit 2                       |
| `ssg -i docs -o .`                | Refused (output contains input), exit 2                        |
| `ssg -i docs -o docs/out`         | Allowed; `docs/out` is not read back as input                  |
| `docs/v1.2.notes.txt`             | Produces `v1.2.notes.html`                                     |
| `docs/a.txt` and `docs/a.md`      | One `a.html` (from `a.md`, first in sort order) plus a warning |
| `docs/index.md`                   | Becomes `index.html`, no menu generated                        |
| `docs/style.css`                  | Ignored. Not a page, not in the menu                           |
| `-c config.json -i other`         | `other` wins over config `input`                               |
| `-c bad.json`                     | Clear JSON error, exit 2                                       |
| No `-s`                           | No `<link rel="stylesheet">` in output                         |
| Running the CLI                   | Terminal is not cleared                                        |
